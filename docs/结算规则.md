# CompriX 远期现金结算规则（一页纸）

> 对客可读摘要。战略背景见 [PRODUCT_V4_算力远期与对冲.md](./PRODUCT_V4_算力远期与对冲.md)。

## 合约在说什么

双方约定到期日参考平台结算价 **S**，锁定价 **X**，数量 **qty**。默认 **现金结算差价**，不强制交割算力。

## 差价怎么算

以买方（多头）视角：

```
signed = (S − X) × qty
```

| signed | 含义 |
|--------|------|
| > 0 | 卖方应付买方（涨价补偿买方） |
| < 0 | 买方应付卖方（跌价补偿卖方） |
| = 0 | 无收付 |

账单记录 **金额绝对值** + **收付方向**；出账后字段只读。

## 确认

1. Broker 登记开仓 → `待确认`。
2. 买方、卖方前台各自确认；或 Broker **代理确认**（必填备注留痕）。
3. 默认 **72 小时**未齐确认 → 自动取消。
4. 双方确认齐 → `持仓中`。

## 到期结算

1. 取到期日已发布 S；若无，取到期日或之前最近已发布 S，并记录所用日期。
2. 生成结算账单；线下收付后 Broker 在后台确认。
3. 不写入现货订单。

## 不做

保证金自动划扣、客户自助挂单、提前平仓/转让（本轮）。对外真钱前须有书面资金流与适当性方案。

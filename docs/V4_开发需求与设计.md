## 1. 产品目标（一句话）

**CompriX 要成为算力市场价格发现与价格风险管理平台：**  
今天帮客户看清行情、高效完成询价成交；进一步用远期合约锁定未来算力成本——多数情况只结算差价，真正要卡时再走交割通道。

| 层次 | 目标 |
|------|------|
| 近期 | 现货行情大厅 + Broker 成交协作（线下谈、线上记）可稳定运营 |
| 中期 | 价格指数 + 远期现金结算跑通，形成可演示、可试运行的对冲工具 |
| 长期 | 合约跑通越多 → 结算价与远期曲线越可信 → 吸引更多对冲与成交 |

**北星指标：** 每月成功完结的**现金结算远期合约笔数**。

---

## 2. 核心业务逻辑（对外可讲清）

客户约定到期锁定价格 **X**，平台在到期日给出结算价 **S**：

| 市场变化 | 现金结果 | 客户综合成本 |
|----------|----------|--------------|
| 涨价（如 S = 1.5X） | 卖方补偿买方差价 | 用补偿款按市价买算力，综合约等于 X |
| 跌价（如 S = 0.7X） | 买方补偿卖方差价 | 市价更便宜，加上已付差价，综合约等于 X |

- **主路径（目标结构 ≥ 90%）：** 现金结算差价，不强制搬迁算力。  
- **辅路径（目标结构 ≤ 10%）：** 到期确需算力时，走实物交割通道（如润泽等合作方）。

原则：**先对冲、后交割；先有可信结算价，再扩大合约规模；前期半人工合约台，不做自动撮合交易所。**

## 3. 功能范围（完整能力地图）

### 3.1 现货协作（已具备，持续运营）

| 能力 | 客户侧 | 运营 / Broker 侧 |
|------|--------|------------------|
| 行情 | 参考价（低/中/高、涨跌）、热门板、Live 刷新、通告、脱敏成交动态 | 录入参考价、通告、发布成交动态、SKU 运营字段 |
| 询价成交 | 登录、结构化询价、报价倒计时确认/拒绝、订单进度 | 询价池分配、正式报价、订单五态推进、附件 |
| 财务 | 可见订单与进度 | 应收/应付/赔付线下收付后系统记账 |

### 3.2 价格指数（已具备）

| 能力 | 说明 |
|------|------|
| 指数标的 | 定义可结算的价格标的（首发 1 个，如 H100 包月类） |
| 日结算价 S | 每个交易日产出并可发布；异常跳变需复核后发布 |
| 对客可见 | 前台可查看指数与历史结算价；规则一页纸可读 |
| 防篡改 | 某日结算价一旦用于合约结算，不可再改价或撤销 |

### 3.3 远期合约与现金结算（已具备）

| 能力 | 说明 |
|------|------|
| 开仓登记 | Broker 登记买方、卖方、标的、数量、锁价 X、到期日；默认现金结算 |
| 双边确认 | 买卖双方前台确认；Broker 可代理确认并留痕；超时未确认自动作废 |
| 持仓 | 客户查看待确认 / 持仓中；按最新结算价估算浮动盈亏（标注非最终） |
| 到期结算 | 按结算价 S 计算差价账单；金额与方向固化；线下收付后后台确认 |
| 运营看板 | 完结合约数（北星）、待确认数、待发布指数等 |

### 3.4 实物交割通道（已具备）

| 能力 | 说明 |
|------|------|
| 通道准入 | 与算力商约定可交割标的与服务能力 |
| 白名单 | 仅开通账户可申请实物交割 |
| 申请窗口 | 到期前规定窗口内申请；审核后下发交割工单 |
| 结构监控 | 实物交割占比可见，防止名义对冲实质全交割失控 |

### 3.5 价格曲线与置信度（后置）

同图展示现货参考价、历史结算价、远期开仓点；用成交与结算样本衡量曲线可信度。不阻塞前序闭环。

## 4. 功能边界（明确不做 / 另轨）

| 类别 | 内容 |
|------|------|
| 本阶段不做 | 自动撮合 / 连续竞价、客户自助挂远期单、保证金自动划扣与托管、提前平仓与合约转让、多腿组合、交割通道独立门户、散户高杠杆 |
| 表述边界 | 对外称「算力价格风险管理 / 远期合约协作」；审慎使用「交易所」直至牌照与资金方案明确 |
| 资金边界 | 系统先记状态与账单，款在线下；**对外真钱试运行前**须有书面资金流与适当性方案（法务/业务门禁，非功能开发本身） |

---

## 5. 角色与职责（汇报用）

| 角色 | 要完成的事 |
|------|------------|
| 买方（对冲需求方） | 看结算价 → 确认合约 → 盯持仓 → 到期收/付差价 |
| 卖方（对冲供给方） | 同上（空头侧）；须为可登录账户，与「交割通道算力商」角色分开 |
| Broker / 运营 | 谈判定价、登记开仓、催确认或代理确认、发布结算价、批结算、确认收付 |
| 交割通道方 | 承接少数实物交割工单（计划阶段；首期可由 Broker 线下协同） |

## 7. 阶段验收标准（给领导看的「做完了」）

### 已完成（可演示）

1. 现货：客户能看价、询价、确认报价、跟订单；Broker 能报价、推进履约、记账。  
2. 指数：可发布日结算价；异常跳变可复核；已用于结算的价格不可改。  
3. 远期现金：  
   - 涨价故事：X=100，S=150 → 买方应收差价；  
   - 跌价故事：X=100，S=70 → 买方应付差价；  
   - 确认超时自动取消；Broker 代理确认可留痕；  
   - 运营看板可见完结合约数。  
4. 实物交割：白名单账户在窗口内申请 → 审核 → 工单完成；实物占比可查；已交割不再现金结算。

### 下一阶段（曲线增强）

5. 现货参考价 / 结算价 S / 远期开仓点同图；样本置信度（后置，不阻塞试运行）。

### 对外真钱试运行额外条件（非开发清单）

书面资金流、适当性与合规口径评审通过后再对真实客户放量。

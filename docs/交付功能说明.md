> **用途**：把现网产品交给客户试用时的一页说明——入口、账号、建议路径、能做什么、暂不做什么。  
> **现网**：https://computx.webinfra.cloud/scu/  
> **文档版本**：2026-08-02（客户试用）  
> **设计细则**（内部）：[产品设计与需求.md](./产品设计与需求.md)

## 0. 试用前请先读这 5 条

1. **这是线上可操作环境**，主链路已打通，适合业务试用与演示，不是纸面原型。  
2. **资金为平台账本（Ledger）记账**，不是银行托管或自动扣款；试用余额由运营入金，**不涉及真实打款**。  
3. **定位是「人谈机记」**：价格与条款可在线下谈妥，系统负责报价、状态、冻结/划转与结算记录——**不是**连续竞价交易所。  
4. **建议先用客户前台**走完「看行情 → 控制台 → 询价 / 挂单 / 预售」；管理后台与伙伴门户由我方或授权伙伴使用。  
5. 试用中价格、样本与公告可能随演示数据变动；**指数与参考价不构成要约**，规则摘要见前台「服务与保障」。

## 1. 产品一句话

**CompriX 是算力 / Token 市场的「价格发现 + 价格风险管理」协作平台。**

| 要记住的 | 含义 |
|----------|------|
| **先发现价格** | 用成交样本形成日结算价 **S**，对客可见日公告 |
| **再管风险** | 用预售 / 远期锁定未来成本 **X**，到期按 `(S − X) × 数量` 现金差价结算 |
| **先对冲、后交割** | 默认现金结算；确需算力时，白名单客户可在窗口内申请实物交割 |

**涨跌直觉（买方）**

| 市场 | 现金结果 | 综合成本直觉 |
|------|----------|--------------|
| 涨价（S 高于 X） | 卖方补偿买方 | 补偿款 + 市价采购，接近锁定价 X |
| 跌价（S 低于 X） | 买方补偿卖方 | 市价更低，加上已付差价，仍接近 X |

对外表述建议：称「价格风险管理 / 远期协作 / 价格发现」；认购 / 认沽对客称**使用权 / 保障服务**。

现货挂单、预售保证金、权利金都依赖 **Ledger 可用余额**。

1. 客户用买方账号登录 → 打开「控制台」看可用 / 冻结。  
2. 若余额不足：由我方 Admin 在后台 **财务（Ledger）→ 入金**。  
3. 试用结束可申请出金（运营审核）；全程为演示记账。

## 3. 建议试用路径（约 20～40 分钟）

按顺序走即可覆盖主价值；带 * 的步骤需要我方后台配合。

| 序 | 客户在前台做什么 | 我方配合（如需） | 看到什么算成功 |
|----|------------------|------------------|----------------|
| 1 | 不登录或登录后打开 **行情** | — | 参考价、通告、日公告条、脱敏成交动态 |
| 2 | 打开 **指数**、**服务与保障** | — | 已发布结算价 S；规则摘要可读 |
| 3 | **控制台** 看资金与待办 | * 不足则入金 | 可用 / 冻结数字合理 |
| 4 | **询价** 提交一笔 RFQ | * Broker 发正式报价 | 客户可确认 / 拒绝报价 |
| 5 | **现货挂单** 挂限价买单（或与卖方对敲） | * 对手盘 / 入金 | 冻结 → 成交 → 余额变化 |
| 6 | **预售** 挂牌买入 → 双方确认 | 卖方账号确认；或 Broker 代开 | 持仓出现，保证金已冻 |
| 7 | （可选）**权益** 自助认购 | * 运营确认收取权利金 | 控制台可见待办 / 持仓 |
| 8 | （可选）窗口内 **交割申请** | * 白名单已开；运营审工单 | 工单进入交割流程 |

**最短 10 分钟版**：行情 → 控制台（入金后）→ 预售买入并双边确认 → 看持仓。

## 4. 客户前台：能试用的功能

**端适配**：移动端底栏 5 入口 +「更多」；桌面（≥1024px）顶栏全导航。列表页小屏卡片 / 大屏表格；表单触控区约 44px；禁止横向撑破视口。

| 模块 | 你可以做什么 | 注意 |
|------|--------------|------|
| **行情** | 看参考价低/中/高、涨跌、热门 SKU、通告、日公告、脱敏成交；约 30 秒刷新 | 游客可看公开部分 |
| **指数** | 查看各区域已发布结算价及历史 | 仅已发布 S 可用于结算 |
| **现货挂单** | 限价买卖、看盘口、取消未成交 | 需可用余额；卖单受伙伴产能约束；量大时引导走询价 |
| **询价** | 结构化询价 → 等正式报价 → 确认 / 拒绝 | 线下谈妥后由系统记状态与 Payment |
| **预售 / 持仓** | 挂牌买入锁价、确认合约、交割意愿、窗口内申请实物交割 | 默认现金结算；实物需白名单 |
| **权益** | 自助买入认购（使用权）/ 认沽（保障服务）、确认、窗内行权 | 须运营确认收取权利金后再生效相关动作 |
| **控制台** | 资金、持仓摘要、账单摘要、追保 / 确认 / 行权等待办 | **每日建议先看这里** |
| **账单** | 查看现金结算差价账单 | 只读；线下收付由 Broker 确认 |
| **账号 / 服务与保障** | 改密；阅读指数 / 结算 / 交割规则摘要 | — |

## 5. 主业务怎么走（客户视角）

### 5.1 看清价格（价格发现结果）

运营每日形成区域结算价 **S** 并发布日公告后，你会在：

- 行情页公告条  
- 指数页  
- 控制台相关摘要  

看到正式结果。未发布的价格不能用于结算。

### 5.2 买一笔现货

**方式 A · 询价（半人工，适合大宗）**

```
提交询价 → 收到正式报价 → 确认
→ 订单按履约状态推进 → 线下收付由后台 Payment 记账
```

**方式 B · 挂单（入金后限价撮合）**

```
Ledger 有余额 → 挂限价单 → 对手成交
→ 买方全额扣款、卖方入账 → 可申请出金
```

### 5.3 锁未来成本（预售）

```
有余额 → 「预售」选挂牌与数量、锁价 X → 提交
→ 买方确认 + 卖方确认 → 持仓（保证金已冻）
→ 到期按已发布 S 出账单，或窗口内申请实物交割
```

默认对手方可为平台卖方试用账号；也可由 Broker 指定双方。开仓会校验敞口限额与保证金。

### 5.4 使用权 / 保障服务（权益）

```
有余额 → 自助开仓 → 买方确认 → 运营确认收取权利金 → 窗内行权
```

页面上的 IV / TV / Δ 等为**简化参考**，不是完整期权定价引擎。权益损益图：后端给出完整 `payoff`，前端按图展示（K / 盈亏平衡 / 现货 / 最大亏损 / 隐含损益）。

### 5.5 实物交割（辅路径）

- 须在交割**白名单**（种子买方已开；新客户由运营开通）。  
- 须在到期前约 **7 天～到期日**窗口内申请（可配置）。  
- 运营批准后走工单，**不再走该合约的现金结算**；争议由人工裁定。

## 6. 试用边界（避免期望偏差）

| 现网已具备 | 本阶段不做 / 须另立方案 |
|------------|-------------------------|
| 三端 Web，主链路可试用 | 连续竞价「交易所」牌照形态 |
| 日结算公告、行情日切、指数对客展示 | 银行托管、自动支付网关、真钱自动扣款 |
| 预售自助、现金结算、敞口与保证金 | 提前平仓、合约转让、多腿组合 |
| 挂单簿 + 询价 + Ledger / Payment 分离 | 链上结算、AI 自动报价 |
| 认购 / 认沽（简化模型）、规则摘要页 | 完整 BS / 实时 IV 曲面；曲线「可信度」外数据图 |
| 交割白名单 / 工单 / 争议；伙伴 Bid/Ask | 测速 / K8s 纳管等基础设施产品；原生 App |

**资金说明**：Ledger / Payment 均为协作记账；对外「真钱自动结算」不在本试用范围。

## 7. 试用反馈建议勾选

试用结束后可用下列项对齐感受（不必全部点满）：

- [ ] 能打开前台，用买方账号登录  
- [ ] 行情与已发布指数 / 公告可理解  
- [ ] 控制台能看清资金与待办  
- [ ] 询价或挂单至少走通一种现货路径  
- [ ] 预售开仓 + 双边确认后可见持仓与保证金冻结  
- [ ] （如试用）交割申请或权益路径有闭环反馈  
- [ ] 已知「非交易所、非银行托管」边界，无重大误解  

问题与改进建议请直接反馈对接人；接口级验收矩阵见内部 [测试说明.md](./测试说明.md)。

## 附录 A · 我方陪同试用（运营一日速查）

外部客户一般只拿前台账号；下列供我方陪同人员使用。

### A.1 客户一天怎么用（可转述）

1. 行情看价与公告 → 控制台看资金与待办。  
2. 现货：询价 **或** 挂单（先入金）。  
3. 锁价：预售买入 → 双方确认。  
4. 权益 / 交割：按需，配合运营确认与审核。

### A.2 Broker / Admin 配合清单

| 场景 | 操作 |
|------|------|
| 客户没钱 | Admin：Ledger 入金 |
| 询价卡住 | Broker：询价池发正式报价，推进订单；Payment 记线下收付 |
| 要正式 S | 价格发现：录入样本 → 跑引擎 → **账号 A 提交、账号 B 发布** → 导出素材可选 |
| 预售 / 权益 | 远期台 / 权益台；代理确认、确认收费 |
| 交割 | 白名单、工单批准 / 争议；看实物占比（目标结构偏现金） |
| 伙伴 | 审核开通、调产能；确认意向成交进样本 |

### A.3 伙伴门户（授权伙伴）

| 能做 | 不能做 |
|------|--------|
| 维护 Bid / Ask、报意向成交、上传交割凭证 | **不可自改产能余量**；意向须运营确认后才进指数样本 |

### A.4 两套账勿混用

| 账本 | 管什么 |
|------|--------|
| **Ledger** | 挂单、预售保证金、权利金、差价、入金出金 |
| **Payment** | RFQ 订单线下应收 / 应付 / 赔付 |

### A.5 内部能力分层（备忘）

```
L4  曲线 · 风控作业 · 客户控制台待办
L3  实物交割 · 伙伴凭证
L2  预售/远期 · 认购/认沽
L1  价格指数 S · 日公告
L0  行情大厅 · RFQ · 挂单簿 · 记账
```

### A.6 现货盘口数据说明

- **五档盘口**仅展示真实挂单；做市/伙伴报价单独标「参考」，不进档位、不参与撮合。  
- 演示数据（幂等，`db:seed` 末尾也会跑）：
  - `npm run db:seed:spot-book` — H100·上海阶梯挂单
  - `npm run db:seed:buyer-holdings` — 买方合理预售/权益；卖方演示入金；作废错标的脏单
- 开仓校验：权益行权价须落在现货约 0.2×～5×，避免再出现「H100 行权价 3」类烟测脏数据。  
- 每个 SKU+区域仅一个活跃结算指数；日结算价曲线直接读已发布 S。

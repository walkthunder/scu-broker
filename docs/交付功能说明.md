## 1. 产品是什么

**CompriX（硅元引擎）是算力与 Token 市场的「价格发现 + 价格风险管理」协作平台。**

它不是连续竞价的交易所，也不是自动托管银行。定位是：

| 一句话 | 含义 |
|--------|------|
| **人谈机记** | 价格与条款多在线下谈妥，系统负责记状态、报价、资金冻结/划转、脱敏动态与结算 |
| **先发现价格，再管风险** | 用真实渠道成交样本形成日结算价，再支撑预售/远期对冲 |
| **先对冲、后交割** | 默认用现金差价对冲成本；确需算力时再走少数实物交割 |

### 1.1 核心故事（对外必讲清）

客户与对手方约定到期锁定价格 **X**，平台到期发布结算价 **S**：

| 市场走势 | 现金结果（买方视角） | 客户综合成本直觉 |
|----------|----------------------|------------------|
| 涨价（例如 S = 1.5X） | 卖方补偿买方差价 | 用补偿款按市价买卡，综合接近 X |
| 跌价（例如 S = 0.7X） | 买方补偿卖方差价 | 市价更低，加上已付差价，综合接近 X |

- **主路径（目标结构 ≥ 90%）**：到期现金结算差价，不强制搬迁算力。  
- **辅路径（目标结构 ≤ 10%）**：到期确需算力 → 白名单客户申请实物交割。

### 1.2 产品能力分层

```
L4  曲线 · 风控作业 · 客户控制台待办
L3  实物交割（白名单 · 窗口 · 工单 · 争议）· 伙伴凭证
L2  预售/远期（保证金 · 盯市 · 现金结算）· 认购/认沽
L1  价格指数 S · 价格发现引擎 · 双人复核日公告
L0  行情大厅 · RFQ 询价成交 · 现货挂单簿 · 线下收付记账
```

## 5. 完整业务能力与操作路径

### 5.1 价格发现与日结算公告（L1）— 平台可信度底座

**做什么**：把分散的真实成交样本，变成当日各区域结算价 **S**，并形成可对客展示的日价格公告。

**运营路径（建议双人）**

1. **录入样本**：价格发现页手工录入或 CSV 导入渠道成交；或伙伴上报意向后，运营点确认。  
2. **跑引擎**：加权样本测算；样本不足时用做市双边报价 / 伙伴报价均值 / 昨结 / 参考价插值。  
3. **账号 A 提交公告** → 状态待复核。  
4. **账号 B（另一人）复核发布** → 正式结算价生效。  
5. **导出素材**：打开 HTML 导出 → 浏览器打印 PDF 或下载长图 PNG。  
6. **对客可见**：客户行情页公告条、指数页、控制台。

**规则要点**

- 每个交易日、每个指数最多一条**已发布** S。  
- 未发布不可用于结算；已写入结算账单的 S **禁止改价/撤销**。  
- 指数与参考价**不构成要约**。

---

### 5.2 现货协作（L0）— 谈成一笔算力买卖

#### A. 行情大厅（无需登录可看公开部分）

看参考价区间、涨跌、热门板、通告、脱敏「某区域 · 某 SKU · 成交类型 · 日期」动态。

#### B. RFQ 询价成交（半人工主路径）

```
客户提交询价 → Broker 正式报价 → 客户确认/拒绝
       → 生成订单 → 履约五态 → Payment 线下收付记账
```

| 步骤 | 角色 | 操作位置 |
|------|------|----------|
| 1 | 客户 | 前台「询价」填写 SKU、区域、数量、交期等 |
| 2 | Broker | 后台询价池 → 发正式报价（默认约 24h 有效） |
| 3 | 客户 | 报价详情确认或拒绝 |
| 4 | Broker | 订单：待签约 → 待交付 → 待验收 → 待结算 → 已完成 |
| 5 | 财务 | Payment 登记应收/应付（线下打款，系统记账） |

#### C. 现货挂单簿（入金后限价撮合）

```
Admin 入金 → 客户挂限价单 → 对手成交 → Ledger 全额划转
```

| 步骤 | 角色 | 说明 |
|------|------|------|
| 1 | Admin | Ledger 给客户入金 |
| 2 | 客户 | 「现货挂单」选 SKU/区域/方向/价格/数量 |
| 3 | 系统 | 买方按**全额名义**冻结；冲击过大提示改走 RFQ |
| 4 | 成交 | 买方扣款、卖方入账；受伙伴产能余量约束 |
| 5 | 客户 | 可取消未成交部分；可申请出金（运营审核） |

---

### 5.3 预售 / 远期对冲（L2）— 锁定未来成本

**产品名「预售」= 系统远期合约。** 默认现金结算。

#### 路径一：客户自助买入（演示首选）

```
入金 → 预售挂牌（建议价 + 相对现货折让%）→ 提交开仓
    → 买方确认 + 卖方确认 → 持仓（保证金已冻）
    →（可选）交割意愿 cash/physical
    → 到期现金结算账单 或 窗口内申请实物交割
```

| 步骤 | 谁 | 在哪 |
|------|----|------|
| 1 | Admin | Ledger 入金 |
| 2 | 买方客户 | 「预售」选挂牌、数量、锁价，提交 |
| 3 | 买方 + 卖方 | 各自确认（超时默认约 72h 作废） |
| 4 | 系统 | 冻结初始保证金；开仓后盯市；追保进控制台待办 |
| 5a | 系统/运营 | 到期按已发布 S 出账单：`(S − X) × qty` |
| 5b | 白名单客户 | 到期前窗口内申请实物 → 运营审核工单 |

默认对手方为平台卖方种子账号（`seller@comprix.local`）；也可由 Broker 指定双方开仓。

#### 路径二：Broker 代开仓

后台「远期」登记指数、买卖方、数量、锁价 X、到期日 → 双方前台确认或 Broker 代理确认（留痕）。

**开仓前强制**：单客户 / 全平台**名义敞口限额**校验；可用保证金充足。

---

### 5.4 认购 / 认沽（使用权 / 保障服务）

| 类型 | 对客含义 | 窗内权利 |
|------|----------|----------|
| **认购** | 使用权类安排 | 优先按约定安排交割；到期未行权权利金不退 |
| **认沽** | 保障服务类安排 | 按约定回售并差价结算；受认沽资金池约束 |

**操作路径**

```
入金 → 客户自助或 Broker 开仓 → 买方确认
    → 运营确认收取权利金 → 窗内行权
```

前台展示参考权利金的 **IV / TV / 内在价值 / Δ** 与简化损益说明（近似模型，非完整期权定价引擎）。

---

### 5.5 实物交割（L3）— 辅路径

**前提**：客户在交割白名单；合约持仓中；处于到期前 N 天～到期日窗口（N 可配置，默认 7）。

```
客户申请交割 → 运营审核
  ├─ 批准 → 工单：交割中 → 完成/对账 → 合约已交割（不再现金结算）
  ├─ 争议 → 人工裁定（不自动扣款）
  └─ 驳回 → 可回到现金路径（视状态）
伙伴上传凭证 → 运营核对
违约 → 可扣保证金 / 可选拉黑
```

运营看板监控实物占比，目标结构 **≤ 10%**。

---

### 5.6 资金：两套账，勿混用

| 账本 | 管什么 | 谁操作 |
|------|--------|--------|
| **Ledger** | 挂单冻结/成交、预售保证金、权利金、现金结算差价、入金出金 | Admin 入金出金；系统自动冻结划转；客户控制台可见 |
| **Payment** | RFQ 订单线下应收应付/赔付 | Broker/财务在后台记账 |

对外「真钱自动扣款 / 银行托管」不在本阶段范围；上线前须另立资金与适当性方案。

## 6. 角色操作路径速查（一页纸）

### 客户买方 · 一天怎么用

1. 打开行情，看价与公告。  
2. 控制台看资金与待办（确认合约、追保、行权）。  
3. 要现货：询价 **或** 挂单（先确保已入金）。  
4. 要锁价：预售挂牌买入 → 确认 → 持有到结算或申请交割。  
5. 要权利类安排：权益自助买入 → 确认 → 等运营收费 → 窗内行权。

### Broker · 一天怎么用

1. 清询价池，发正式报价，推订单状态。  
2. 录入参考价 / 渠道成交；配合另一人完成日公告发布。  
3. 远期/权益台处理开仓与收费确认。  
4. 交割工单审批；CRM 跟进线索。

### Admin · 额外必做

1. 客户 Ledger 入金 / 出金。  
2. 伙伴审核与产能调整。  
3. 平台参数与风控作业；必要时导出公告素材。

### 伙伴 · 一天怎么用

1. 更新 Bid/Ask。  
2. 有真实意向成交则上报，等运营确认。  
3. 有交割任务则上传凭证。

## 8. 交付边界（避免期望偏差）

| 已交付 | 本阶段不做 / 须另立方案 |
|--------|-------------------------|
| 三端 Web + API，主链路可演示可验收 | 连续竞价「交易所」牌照形态 |
| 双人复核日公告、曲线、做市插值 | 银行级保证金自动托管、自动支付网关 |
| 预售自助/Broker、现金结算、敞口限额 | 提前平仓与合约转让、多腿组合 |
| 挂单簿 + RFQ + Payment/Ledger 分离 | 链上结算、AI 自动报价 |
| 认购认沽（简化参考价） | 完整 Black–Scholes / 实时 IV 曲面 |
| 实物交割 + 争议 + 伙伴凭证 | 测速 / K8s / 容器纳管等基础设施产品 |
| CRM、风控日作业、伙伴报价 | 原生 App、新加坡站等二期项 |

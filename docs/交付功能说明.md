## 1. 一句话交付物

交付一套可演示、可验收的**三端 Web + API**：客户门户、运营后台、供给伙伴门户；覆盖行情与指数、现货协作、预售/远期对冲、认购认沽、实物交割、账本资金、价格公告与风控作业。

## 3. 已交付能力总览（按业务链路）

### 3.1 价格发现与日公告（FRD 核心）

- 渠道成交采集（手工 / CSV / 伙伴意向 → 运营确认后进样本）
- 指数引擎：加权样本测算；样本不足时用**做市双边报价**与昨结/参考价插值
- **双人复核**提交 → 发布价格公告（正式结算价 S）
- 对客：行情页公告条、指数页、控制台可见最新公告
- **公告素材导出**：打印/另存 PDF、下载长图 PNG（运营后台一键打开）
- 价格曲线：日 / 周 / 月

### 3.2 现货协作

- 参考价行情大厅、热门 SKU、脱敏成交动态
- RFQ：结构化询价 → 正式报价 → 确认 → 订单五态 + Payment 线下收付记账
- **挂单簿**：限价买卖、冲击过大引导 RFQ；买方按**全额名义**冻结，成交后买方扣款、卖方入账
- 产能约束（伙伴余量）

### 3.3 预售 / 远期（价格风险管理主路径）

- Broker 开仓 **或客户自助买入预售**（挂牌展示建议价与相对现货**折让%**）
- 默认对手方为平台卖方种子账号；双边确认后开仓；超时作废
- 初始保证金冻结、盯市浮动盈亏、追保进控制台待办
- 单客户 / 全平台**名义敞口限额**开仓前强制校验
- 到期现金结算账单 `(S−X)×qty`；或窗口内申请实物交割
- 交割意愿：现金 / 实物

### 3.4 认购 / 认沽（使用权 / 保障服务表述）

- Broker 开仓 **或客户自助买入**
- 参考权利金展示 **IV / TV / 内在价值 / Δ** 与损益图
- 买方确认 → 运营确认收费 → 窗内行权
- 认沽资金池覆盖校验

### 3.5 实物交割

- 白名单、到期窗口、通道、工单流（待审→批准→交割中→完成→对账）
- **争议**状态（人工裁定，不自动扣款）
- 违约处置（可扣保证金、可选拉黑）
- 伙伴上传交割凭证；实物占比看板目标结构 ≤10%

### 3.6 资金账本（Ledger）

- 运营**入金 / 出金**
- 可用 / 冻结余额；客户控制台可见资金与待办
- 与 RFQ Payment 分离：衍生品走 Ledger，询价订单走线下收付台账

### 3.7 伙伴与 CRM / 风控

- 伙伴申请审核、产能、正式双边报价字段、意向成交
- CRM 线索、笔记、标记成交
- 日作业：发布预备、追保、盯市快照、过期清理（可关调度）

## 4. 对照 FRD：已闭环 vs 边界说明

| FRD 诉求（摘要） | 交付状态 | 说明 |
|------------------|----------|------|
| 区域指数 + 全国综合价 + 日公告 | ✅ 已交付 | 双人复核；对客可见 |
| 渠道成交样本 → 结算价 | ✅ 已交付 | 含伙伴意向确认 |
| 样本不足插值 / 做市参考 | ✅ 已交付 | `MakerQuote` + 引擎插值 |
| 公告 PDF / 图素材 | ✅ 已交付 | HTML 导出打印 PDF / PNG |
| 预售定价（现货×基差） | ✅ 已交付 | 挂牌建议价 + 折让% |
| 客户买预售闭环 | ✅ 已交付 | 自助买入 + 双边确认 + 保证金 |
| 现货挂单与资金 | ✅ 已交付 | 全额冻结与成交划转；入金出金 |
| 敞口限额 | ✅ 已交付 | 单客/平台名义强制 |
| 认购认沽 + 参考价 | ✅ 已交付 | 自助 + IV/TV 展示（简化模型，非完整 BS 引擎） |
| 实物交割与争议 | ✅ 已交付 | 工单 + 争议 + 违约 |
| 伙伴产能与报价 | ✅ 已交付 | Bid/Ask 字段 |
| 银行级托管 / 自动支付网关 | ⚠ 边界 | Ledger 记账模型；真钱对接须另立资金与合规方案 |
| 连续竞价「交易所」 | ❌ 本阶段不做 | 半人工合约台 + 挂单簿，非交易所牌照形态 |
| 完整 Black–Scholes / 实时 IV 曲面 | ⚠ 简化 | 权利金为可解释近似公式 + 参数配置 |
| VaR 全面风控、新加坡站、原生 App | ❌ 二期外 | FRD Phase2/3 明确后置 |

## 5. 建议演示脚本（30 分钟）

1. **价格发现**：录入一笔渠道成交 → 跑引擎 → 提交公告 → 另一账号复核发布 → 打开导出素材。  
2. **预售**：客户登录 →「买入预售」选挂牌 → 提交 → 买卖双方确认 → 控制台看保证金与盯市。  
3. **现货**：入金 → 挂买单 → 对手成交 → 看账本可用/冻结变化 → 出金。  
4. **权益**：自助买入认购 → 确认 → 运营收权利金 → 看 IV/TV 与损益图。  
5. **交割/争议**：白名单客户窗口内申请 → 运营批准或标争议。  
6. **伙伴**：改产能与 Bid/Ask → 报意向成交 → 运营确认计入指数。

# 硅元引擎 / CompriX FRD 实现映射

对照《硅元引擎功能需求文档_FRD》（国内 MVP）。**全量落地，不分期**；架构图中的测速/容器纳管/K8s 调度不在范围。

## 产品端到端（可走完）

| 链路 | 角色路径 | 关键入口 |
|------|----------|----------|
| 价格发现 | 录入/CSV → 引擎 → **双人不同账号**复核发布 → 行情条+控制台看公告 | 后台「价格发现」；前台「行情」公告条 |
| 现货挂单 | 财务**账本入金** → 挂单/成交/取消 → 大额引导询价 | 财务入金；前台「现货」 |
| RFQ 现货 | 询价 → 报价 → 订单 → Payment 收付款 | 询价 / 询价台 / 财务 |
| 6 月预售 | 入金 → 开仓确认 → 交割意愿 → 现金结算/实物交割 → 账单确认 | 远期台 / 预售 / 交割 / 结算账单 |
| 认购/认沽 | 入金 → 开仓 → 客户确认 → 权利金确认 → 行权 | 后台权益；前台「权益」主导航 |
| 伙伴 | 申请 → 审核开通 → 改产能 → 报意向成交（运营确认）→ 凭证 | 伙伴门户 + 后台伙伴 |
| CRM | 注册带来源 → 线索/阶段/笔记 → **标记成交**关联 user | 后台 CRM |
| 风控 | 作业追保/盯市单 → 控制台待办可点（含追保） | 风控；控制台 |

## 架构原则（大道至简）

| 真理源 | 职责 | 不要混用 |
|--------|------|----------|
| **价格公告双人复核** | 引擎/参考测算价 → 正式结算 `IndexPrint` | 指数台可发 **manual** 覆写价；`engine`/`reference` 源禁止单笔绕过 |
| **Ledger（分账）** | 挂单保证金、权利金、预售保证金、差价结算划转 | 与 RFQ `Payment`（线下应收应付）分离 |
| **ChannelDeal** | 价格发现样本 | DealFeed 仅营销；伙伴成交默认意向，运营确认后计入 |
| **PlatformConfig** | 保证金% 等 | 现货与预售共用 `margin_initial_pct` |
| **交割** | `/api/admin/delivery-orders/*` | 伙伴凭证 `/api/frd/partner/deliveries` |

盯市：风险用 live MTM；`mtm_statements` 为日终快照。

**作业：** `POST /frd/jobs/{daily-publish-prep,margin-monitor,mtm-statements,expire-all,daily-run}`；`FRD_SCHEDULER=0` 可关。

命名：预售 = ForwardContract；认购/认沽 = RightContract。

# CompriX 价格指数规则（一页纸）

> 对客可读摘要。开发目标与阶段计划见 [V4_开发需求与设计.md](./V4_开发需求与设计.md)。

## 是什么

**结算价 S** 是远期现金结算的官方参考价。每个交易日、每个指数标的最多一条已发布 `S`。

## 当前标的（演示种子）

| 代码 | 名称 | 锚定 SKU | 跳变阈值 |
|------|------|----------|----------|
| H100-M | H100 包月结算指数 | H100 包月 | ±20% |
| H100-H | H100 时租结算指数 | H100 | ±20% |
| H800-H | H800 时租结算指数 | H800 | ±20% |
| A100-H | A100 时租结算指数 | A100 | ±25% |
| GPT-T | GPT Token 结算指数 | GPT Token | ±30% |
| DS-T | DeepSeek Token 结算指数 | DeepSeek Token | ±30% |

后台 **价格指数** 可继续新增指数（须选锚定 SKU）。

## 怎么来

1. 每个指数锚定 **1 个 SKU**。
2. 默认：取当日该 SKU 参考价 **中位价 `price_mid`** 生成草稿（后台「从 mid 生成」）。
3. 运营可人工覆写；相对上一 **已发布** S 跳变超过阈值时进入待复核，确认后再发布。
4. **未发布不可用于结算。**

## 日常更新机制

| 步骤 | 谁 | 哪里 | 做什么 |
|------|----|------|--------|
| 1 | Broker/Admin | 后台 → 参考价 | 录入/覆盖当日各 SKU 的低/中/高价 |
| 2 | Broker/Admin | 后台 → 价格指数 | 选指数 →「从 mid 生成」或人工覆写 S |
| 3 | Broker/Admin | 同页 | 「发布」后，客户前台可见，远期结算可用 |
| 4 | — | 自动 | 批结算只取 **已发布** 且日期 ≤ 到期日的最新 S |

## 不可改

某日 S 一旦写入任意远期结算账单，**禁止改价与撤销发布**。

## 不构成要约

指数与参考价均为风险管理参考，不构成买卖要约；正式权利义务以双方确认的远期合约与结算账单为准。

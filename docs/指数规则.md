# CompriX 价格指数规则（一页纸）

> 对客可读摘要。开发目标与阶段计划见 [V4_开发需求与设计.md](./V4_开发需求与设计.md)。

## 是什么

**结算价 S** 是远期现金结算的官方参考价。每个交易日、每个指数标的最多一条已发布 `S`。

## 怎么来

1. 每个指数锚定 **1 个 SKU**（首发：`H100-M` →「H100 包月」）。
2. 默认：取当日该 SKU 参考价 **中位价 `price_mid`** 生成草稿。
3. 运营可人工覆写；相对上一 **已发布** S 跳变超过阈值（默认 ±20%）时进入待复核，确认后再发布。
4. **未发布不可用于结算。**

## 不可改

某日 S 一旦写入任意远期结算账单，**禁止改价与撤销发布**。

## 不构成要约

指数与参考价均为风险管理参考，不构成买卖要约；正式权利义务以双方确认的远期合约与结算账单为准。

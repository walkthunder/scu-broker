## 1. 产品目标

**CompriX 是算力市场的价格发现与价格风险管理平台。**

| 层次 | 目标 |
|------|------|
| 基座 | 现货行情大厅 + Broker 成交协作（**人谈机记**：线下谈、线上记） |
| 核心 | 价格指数 + 远期/预售现金结算，锁定未来算力成本 |
| 增强 | 少数实物交割；挂单簿、认购/认沽、伙伴产能、CRM/风控 |
| 飞轮 | 合约跑通越多 → 结算价与曲线越可信 → 吸引更多对冲与成交 |

**北星指标：** 每月成功完结的**现金结算远期/预售合约笔数**。

### 1.1 核心故事（对外可讲清）

约定到期锁定价格 **X**，平台到期给出结算价 **S**：

| 市场 | 现金结果 | 客户综合成本 |
|------|----------|--------------|
| 涨价（S = 1.5X） | 卖方补偿买方差价 | 用补偿款按市价买卡，综合约等于 X |
| 跌价（S = 0.7X） | 买方补偿卖方差价 | 市价更低，加上已付差价，综合约等于 X |

- **主路径（目标结构 ≥ 90%）：** 现金结算差价，不强制搬迁算力。  
- **辅路径（目标结构 ≤ 10%）：** 到期确需算力 → 实物交割通道。  

### 1.2 产品原则

1. **先对冲、后交割**；先有可信结算价，再扩大合约规模。  
2. **半人工合约台优先**，不做自动连续竞价交易所（本阶段）。  
3. **真实样本校准曲线**，禁止虚构人气/假成交。  
4. **合规表述克制**：称「价格风险管理 / 远期合约协作」；审慎使用「交易所」。  
5. **资金**：Ledger 管衍生品可用/冻结；RFQ `Payment` 管线下应收应付。对外真钱前须书面资金流与适当性方案。  
6. **结算价真理源**：正式结算以**价格公告双人复核发布**为准；指数台可发 `manual` 覆写；`engine`/`reference` 源禁止单笔绕过公告。

### 1.3 明确不做（本阶段）

自动连续竞价交易所、保证金银行级自动托管、提前平仓与转让、多腿组合、IM、链上结算、自动支付 API、AI 自动报价、测速/K8s/容器纳管（FRD 架构图外范围）。  
**已支持：** 客户自助买入预售/权益（对手方为平台默认卖方或运营后续收费确认）；现货挂单簿撮合（非连续竞价交易所）。

## 2. 角色

| 角色 | 入口 | 职责 |
|------|------|------|
| 游客 / 客户 | 前台 | 看行情；登录后询价、确认报价、持仓/预售、权益、控制台、账单、交割意愿 |
| Broker / Admin | 后台 | 询价报价、订单财务、参考价/指数/价格发现、远期台、权益、交割、CRM、风控、伙伴审核 |
| 供给伙伴 | 伙伴门户 | 入驻、产能、意向成交上报、交割凭证 |
| 交割通道方 | 线下 + 工单 | 承接少数实物交割（系统有通道/白名单/工单） |

## 3. 能力地图（已落地）

```
L4  曲线 /frd/curves · 风控作业 · 控制台待办
L3  实物交割（白名单 · 窗口 · 工单 · 占比）· 伙伴凭证
L2  远期/预售（确认 · 保证金 · 盯市 · 现金结算账单）· 认购/认沽
L1  价格指数 S · 价格发现引擎 · 双人公告
L0  现货行情 · RFQ 询价成交 · 挂单簿 · Payment 记账
```

### 3.1 现货协作（L0）

| 能力 | 客户 | 运营 |
|------|------|------|
| 行情 | 参考价低/中/高与涨跌、热门板、通告、脱敏成交动态、≈30s 刷新 | 录入参考价、通告、发布动态、SKU 运营字段 |
| 询价成交 | 结构化询价、报价倒计时确认/拒绝、订单进度 | 询价池、正式报价、订单五态、附件 |
| 挂单簿 | 入金后限价挂单/取消；冲击过大引导 RFQ | 账本入金；产能约束 |
| 财务 | 可见订单进度 | RFQ 应收/应付/赔付线下记账（Payment） |

**RFQ 状态：** `pending → quoted → confirmed \| rejected`  
**Quote：** `draft → pending → confirmed \| rejected \| expired`（默认约 24h）  
**Order：** `待签约 → 待交付 → 待验收 → 待结算 → 已完成`（另有取消/赔付）；变更写 `order_logs`。

### 3.2 价格指数与价格发现（L1）

| 能力 | 说明 |
|------|------|
| 指数标的 | 锚定 SKU + 区域；日结算价 S；跳变超阈值进复核 |
| 价格发现 | 渠道成交（ChannelDeal）样本 → 引擎测算 → **双人不同账号**提交/复核发布公告 |
| 对客 | 前台指数页、行情公告条、控制台可见最新公告 |
| 防篡改 | 某日 S 一旦写入结算账单，禁止改价/撤销 |
| 曲线 | `/api/frd/curves` 日/周/月 |

### 3.3 远期 / 预售与现金结算（L2）

| 能力 | 说明 |
|------|------|
| 开仓 | Broker 登记 **或客户自助买入预售**（默认对手方 `seller@comprix.local`）；标的、qty、锁价 X、到期日；默认现金结算；展示相对现货折让% |
| 确认 | 双边前台确认或 Broker 代理确认留痕；超时（默认 72h）自动作废 |
| 保证金 | Ledger 冻结；`PlatformConfig.margin_*`；盯市追保进控制台待办；单客/全平台名义敞口强制校验 |
| 交割意愿 | `unset / cash / physical`；实物须白名单 + 窗口 |
| 到期结算 | `(S − X) × qty`；账单只读；Ledger 或线下确认收付 |
| 命名 | 产品「预售」= 模型 `ForwardContract` |

### 3.4 实物交割（L3）

白名单 · 到期前 7 天至到期日申请 · 审核后不再现金结算 · 工单完成→已交割 · **争议**状态人工裁定 · 违约可扣保证金/拉黑 · 看板监控实物占比 ≤10% 目标结构。

### 3.5 认购 / 认沽（L2 增强）

对外称**使用权 / 保障服务**，非标准化金融期权。客户可自助买入；认购：窗内优先交割；认沽：窗内回售差价；权利金经 Ledger；参考权利金展示 **IV/TV/内在价值/Δ**（简化模型）；运营确认收费后生效。模型：`RightContract`。

### 3.6 伙伴 / CRM / 风控

| 模块 | 要点 |
|------|------|
| 伙伴 | 申请→审核开通→改产能与 **Bid/Ask 报价**→报意向成交（运营确认后进样本）→凭证 |
| 做市报价 | 运营录入 `MakerQuote`；样本不足时与昨结/参考价插值 |
| 公告素材 | 导出 HTML：打印 PDF / 长图 PNG |
| CRM | 注册来源、线索阶段、笔记、标记成交关联用户 |
| 账本 | 运营入金/出金；现货挂单按**全额名义**冻结，成交全额划转 |
| 风控 | 日作业：发布预备、追保、盯市快照、过期清理；`FRD_SCHEDULER=0` 可关 |

## 4. 端到端路径（验收可走完）

| 链路 | 路径 |
|------|------|
| 价格发现 | 录入/CSV → 引擎（含做市插值）→ 双人复核发布 → 导出素材 → 行情/控制台看公告 |
| 现货挂单 | 财务账本入金 → 挂单（全额冻结）/成交划转/取消 → 出金 |
| RFQ | 询价 → 报价 → 订单 → Payment |
| 预售 | 入金 → **自助或 Broker 开仓** → 确认 → 交割意愿 → 现金或实物/争议 → 账单 |
| 权益 | 入金 → **自助或 Broker 开仓** → 确认 → 权利金 → 行权 |
| 伙伴 | 入驻 → 产能+报价 → 意向成交 → 运营确认 |
| 风控 | 作业追保 → 控制台可点待办 |

## 5. 架构原则（大道至简）

| 真理源 | 职责 | 勿混用 |
|--------|------|--------|
| 价格公告双人复核 | 正式结算 `IndexPrint` | 指数台 `manual` 可覆写；引擎价不可单笔偷发 |
| Ledger | 挂单/权利金/预售保证金/差价划转 | 与 RFQ Payment 分离 |
| ChannelDeal | 价格发现样本 | DealFeed 仅营销；伙伴默认意向 |
| PlatformConfig | 保证金比例等 | 现货与预售共用初始保证金配置 |
| 交割 API | `/api/admin/delivery-orders/*` | 伙伴凭证 `/api/frd/partner/deliveries` |

盯市：风险用 live MTM；`mtm_statements` 为日终快照。  
作业：`POST /frd/jobs/{daily-publish-prep,margin-monitor,mtm-statements,expire-all,daily-run}`。

存量库升级靠启动时 `ensureFrdColumns`（先补列再 `sync`），生产默认 **不** `DB_SYNC_ALTER=1`。

## 6. 对客规则摘要

### 6.1 指数（结算价 S）

- 每个交易日、每个指数最多一条**已发布** S。  
- 默认可由锚定 SKU 当日参考中位价生成；可人工覆写；跳变超阈值须复核。  
- **未发布不可用于结算**；已写入账单的 S 不可改。  
- 指数与参考价**不构成要约**。

### 6.2 现金结算

```
signed = (S − X) × qty   # 买方视角
```

| signed | 含义 |
|--------|------|
| > 0 | 卖方应付买方 |
| < 0 | 买方应付卖方 |
| = 0 | 无收付 |

开仓待确认 → 双边（或代理）确认 → 持仓 → 到期出账单 → 确认收付。

### 6.3 实物交割

仅白名单；窗口为到期前 7 天至到期日；批准后不再现金结算；种子买方/卖方账号已开通白名单（生产须逐户审批）。

### 6.4 认购 / 认沽

认购：窗内按行权价优先交割安排，到期未行权权利金不退。  
认沽：窗内按行权价回售并差价结算；平台控制名义敞口。

## 7. 验收标准

### 7.1 现货

客户能看价、询价、确认报价、跟订单；Broker 能报价、推进履约、记账；无虚构活跃数据。

### 7.2 指数与公告

可发布日 S；异常可复核；已用于结算不可改；双人复核发布公告可走通。

### 7.3 远期现金

- X=100,S=150 → 买方应收；X=100,S=70 → 买方应付。  
- 确认超时取消；代理确认留痕；看板可见完结笔数。

### 7.4 交割 / FRD

白名单窗口申请→审核→工单；入金→挂单；伙伴产能与意向成交；控制台追保待办；权益开仓行权。

### 7.5 自动化测试

`apps/api`：`npm run test:functional`（含 FRD + **页面接口补全** `PAGE-*`）。沙盘：`npm run sandbox:forward`。  
**页面接口覆盖矩阵与缺口台账：** [测试说明.md](./测试说明.md)。

# CompriX 实物交割说明（一页纸）

> 对客 / 运营摘要。开发目标见 [V4_开发需求与设计.md](./V4_开发需求与设计.md)。

## 何时用

远期合约默认 **现金结算差价**。仅当到期确需算力、且账户已开通 **实物交割白名单** 时，可在窗口内申请改走交割通道。

## 申请窗口

合约到期日前 **7 天至到期日当日**（含）。窗口外不可申请。

## 流程

1. 白名单账户在持仓页提交申请，选择交割通道。  
2. Broker / 运营审核：批准后合约转为实物意向，**不再现金结算**；可驳回。  
3. 通道方线下交付后，运营将工单标为完成，合约状态为「已交割」。

## 结构目标

实物交割占比目标结构 **≤ 10%**（产品原则，非监管承诺）。运营看板可查看完结笔数中的实物占比。

## 试运行账号

种子环境默认已为 `buyer@comprix.local` 与 `seller@comprix.local` 开通交割白名单；生产需运营逐户审批。
